# Caisson Foundations near Slope — DeepFM Failure Envelope Predictor

Reviewer-facing web demo of the trained DeepFM surrogate model used in the manuscript.
Enter θ, L/D, V/V₀ to see the predicted V–H–M failure envelope (2D and 3D) and
export the prediction table as .xlsx/.csv.

Desktop GUI source: `SlopeGUI.py` in the accompanying repository.
